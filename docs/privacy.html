Privacy policy.

We collect only the information needed to run playtests and improve the game. Last updated 17 September 2026.

Static previewThis GitHub Pages build collects nothing. It has no forms, no analytics, and no database. The policy below describes the full application build, which runs on a server deployment. GitHub serves these pages and keeps its own standard request logs.

What we collect

Playtest registration: display name, email, and optional device, operating system, and discovery source. Insider signup: email. Feedback and bug reports: the fields you submit, and optional media. Feature ideas: display name if provided, idea text, and a device cookie used to avoid repeat votes. Basic site events store the page, event type, source site, platform, and time; they do not store your IP address or full referrer URL.

Abuse prevention

To stop automated spam, form and vote requests are counted per connection. We store a salted one-way digest of your network address that changes every counting window, never the address itself, and these counters are deleted once their window has passed.

Why we use it

We use registration details to organize playtests, reports to fix the game, ideas to understand player interest, and aggregate events to see which parts of the site help people reach the game. We do not sell personal information.

Storage & access

Submission records are kept in the site database. Uploaded media is held in private object storage. The admin dashboard is restricted to authorized studio accounts. Public idea text and display names are visible to other visitors; do not put private information in an idea.

Retention

Anonymous site events are removed after 90 days during normal site activity. We keep playtest and Insider contact details while those lists are active or until a deletion request is completed. Reports are kept while needed to investigate game issues. A fixed report-retention schedule and direct privacy contact channel must be finalized before a public launch.

Your choices

You can use the game information pages without registering. Registration and Insider messages require consent. If you later receive a studio email, reply to request removal from the relevant list. Public launch will add a dedicated privacy contact method.

Third parties

The local development preview runs on your machine. When hosted, storage and site delivery providers will process data to operate the site; this page will name those providers before public launch. No advertising trackers are installed.
