// The short version

Ratel
Rage.

Ratel Rage is a Nigerian-inspired 2D arcade beat ’em up starring Darki, a street investigator who takes on MC Olodo’s extortion crew on a Lagos street.

The current browser prototype contains one developed combat mission, “The Street Tax.” An Android debug build is in validation.

Genre / 2D beat ’em up Setting / Lagos, Nigeria Status / In development
